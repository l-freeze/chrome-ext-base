# 多言語化

manifest と画面の文言は、Chrome 拡張の標準の仕組み（`chrome.i18n` と `_locales`）で管理します。
英語（`en`）を既定のロケールとし、日本語（`ja`）を用意しています。

## 文言の置き場所

```text
public/_locales/
├── en/messages.json   既定のロケール。キーの一覧の基準
└── ja/messages.json
```

形式は Chrome の `messages.json` です。値を差し込む文言は、名前付きのプレースホルダーを使います。

```json
"noteCount": {
  "message": "$COUNT$ / $MAX$",
  "description": "Characters used and allowed.",
  "placeholders": { "count": { "content": "$1" }, "max": { "content": "$2" } }
}
```

`languageTag` は、そのカタログの言語タグです（`ja`・`en` など）。画面の `lang` 属性と数値の書式に使います。
ブラウザの表示言語と、Chrome が実際に選んだカタログが一致しないことがあるため、カタログ自身に持たせています。

## Chrome がロケールを選ぶ規則

Chrome はブラウザの表示言語に合うロケールを選び、なければ manifest の `default_locale`（`en`）を使います。
キーがそのロケールにない場合も既定のロケールの文言を使います。拡張の利用者が言語を切り替える設定はありません。

## 使い方

- **manifest**: `name`・`description`・`action.default_title` は `__MSG_キー__` で参照します。
  サイドパネル版は、ビルド時に `extensionNameSidepanel`・`actionTitleSidepanel` へ差し替えます。
- **画面**: 起動点が `loadTranslator()` で翻訳を用意し、`I18nProvider` で画面へ渡します。
  コンポーネントは `useI18n()` を使います。

  ```tsx
  const { t, language } = useI18n();
  <span>{t("noteCount", formatter.format(length), formatter.format(MAX_NOTE_LENGTH))}</span>
  ```

  キーの型 `MessageKey` は既定のロケールのカタログから作るため、存在しないキーは型エラーになります。
- **worker**: `createChromeTranslator<MessageKey>(chrome.i18n)` を使います（右クリックメニューの表示名など）。
- **features**: 画面に出す理由はコードで返し（例: `PageCaptureError` の `reason`、`SiteAccess` の `reason`）、
  文言の選択は画面が行います。features は多言語化の仕組みに依存しません。

`ValidationError` などの例外のメッセージは英語の開発者向けの診断です。画面には表示しないため、翻訳の対象外です。
画面に理由を伝える必要がある失敗は、features が理由のコードで返し、画面が文言を選びます。
Coffee の変換結果の「材料:」や、プレビュー用の固定ページ情報はサンプルのデータで、翻訳していません。

## ブラウザプレビュー

`pnpm run dev` などのプレビューには `chrome.i18n` がないため、同じ `messages.json` を読み込んで
`navigator.languages` からロケールを選びます。プレースホルダーと `$1`〜`$9` の置換は `chrome.i18n` と同じ規則です。
カタログはプレビューのときだけ遅延読み込みするため、拡張の配布物には `_locales` の外に重複して入りません。
Chrome で特定の言語を確認する場合は、ブラウザの表示言語を切り替えるか `--lang=en` などを付けて起動します。

## 文言や言語を追加する

- **文言を追加する**: 全ロケールの `messages.json` に同じキーを追加します。プレースホルダーの名前も揃えます。
- **言語を追加する**: `en` を `_locales/<ロケール>/` に複製して翻訳し、`languageTag` をその言語に変えます。
  フォルダー名は Chrome のロケール名（`pt_BR` のように下線区切り）です。
- `pnpm run check` の配布物テストが、manifest が参照する文言が既定のロケールにあること、
  全ロケールのキーとプレースホルダーが既定のロケールと一致することを確認します。
